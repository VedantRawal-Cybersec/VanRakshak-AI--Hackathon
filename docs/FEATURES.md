## Implementation status model

Each feature should be tracked as one of:

- `LIVE` — integrated with a source or working algorithm.
- `REQUIRES_CREDENTIALS` — code exists but deployment secret is needed.
- `REQUIRES_TRAINED_MODEL` — architecture/inference contract exists; model must be trained and validated.
- `NEXT_WORKER_PHASE` — requires raster processing worker infrastructure.

The UI must not hide those distinctions.
